Limits

  • Reviewer: never reviews its own change.
  • Each role reports: changes, IDs, check results, open questions.
  • A gap found in code: back to the knowledge writer.
  • Commits, pushes, pull requests: the coordinator, only when you ask.
  • Merges: the owners.

Run it with your own agent

  1. Create a workspace with the install command.
  2. Open your agent in it.

Check the run

  • It asks before it writes, one question at a time. Questions
  • It changes the knowledge before the code. Workflow
