# Repository skills

A skill picks the procedure for a task and points at the governing docs; it
does not restate rules, establish product contracts or grant publication
permissions. The [team](../agents/README.md) says which agent uses which skill.

- [Software knowledge](software-knowledge/README.md): add or change goals,
  flows, artifact rules, contracts and client pages, then check the docs.
- [Defect triage](defect-triage/README.md): evidence first, then the knowledge
  ID a defect breaks.
- [Backend service](backend-service/README.md): the endpoints, domain behavior,
  persistence, transactions, calls to other services and provider integration
  of a Go service, from approved knowledge.
- [Plain writing](plain-writing/README.md): the text of a page, a picture
  first, then results; cuts by example.

Each directory contains a canonical `SKILL.md` and a navigation README.
