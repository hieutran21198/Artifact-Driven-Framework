Settings

Workspaces

One per line: owner/repo for a GitHub repository, or local:name for a folder added below.

Note for this browser: it cannot keep access to a local folder. After each page load, Reload asks you to choose the folder again, and the browser lists every file in it, which takes longer for a big folder. Chrome and Edge keep the access.

GitHub tokens

A read-only token for each owner of a private repository; owner * is used for any other owner. Kept in this browser tab only, sent only to api.github.com, never exported.

Configuration

Export the workspaces and the chosen refs to a file, to use them in another browser. Tokens are not in it.

Rule coverage

Coverage tells whether each rule is in the code, not whether the project is right. A rule counts as covered when a test of a service, a client or the end-to-end suite names its ID. It does not check that the test passes, that the code does what the rule says, or that the rule is the right one for the business.
Độ phủ chỉ cho biết rule đã có trong code hay chưa, không cho biết project đúng hay sai. Một rule được tính là đã phủ khi có test của service, client hoặc bộ end-to-end ghi tên ID của nó. Nó không kiểm test có pass không, code có làm đúng như rule không, hay rule có đúng nghiệp vụ không.
