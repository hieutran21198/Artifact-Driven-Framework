# Glossary

Each term is defined once, here. Other pages use it without restating it.

| Term | Meaning |
| --- | --- |
| Member | A person who may borrow books. |
| Loan | A book in the hands of one member, from the moment they borrow it until they return it. |
| Due time | The time by which a loan must end. |
| Overdue | A loan that has passed its due time and is not yet returned. |
| Loan limit | The most books one member may hold on loan at once. |
| Withdrawn book | A book taken out of the collection for good. |
