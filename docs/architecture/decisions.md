# Decisions

The architecture decisions of this project. The decisions of the method are in
[Artifact Driven decisions](../governances/artifact-driven/decisions.md).

Each decision has five parts:

- **Decision.** What was chosen.
- **Context.** The problem it solves.
- **Options.** A table of each option, for and against; the chosen one is
  marked.
- **Costs.** What the choice costs.
- **Revisit when.** The event that reopens it.

Record a new decision as a new section. When a decision changes, write the new
one and say in the old one which section replaces it.
