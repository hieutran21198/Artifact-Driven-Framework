# Principles

This chapter holds principles that guide product and technical decisions.

- [KISS — Keep It Simple](kiss/README.md): simple, sufficient solutions that
  preserve required behavior and constraints.

- [DRY — Don't Repeat Yourself](dry/README.md): reuse the same knowledge and
  behavior without coupling unrelated responsibilities.
- [YAGNI — You Aren't Gonna Need It](yagni/README.md): build for approved needs,
  not hypothetical consumers.
