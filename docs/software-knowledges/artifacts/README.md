# Artifacts

One artifact per domain, each served by one service, as the
[domain map](../../architecture/domain-map.md) says. Each one holds the
established knowledge of
its domain under [Artifact Driven](../../governances/artifact-driven/README.md).

- [Book](book/README.md): reference artifact, with every file an artifact can
  have.
- [Member](member/README.md): a second artifact, so that the flows have
  something to cross.
- [Notice](notice/README.md): an artifact of a second service, so that a flow
  crosses two services.
