# Notice

Owns a message sent to a member, and that it is sent once. Rule prefix: `NTC`.
Served by the `notification` service.

- [Specification](specification.md): rules, model and lifecycle.
- [Contract](openapi.yaml): the OpenAPI contract, written before the code.
- [Service](service.md): the domain contract the `notification` service
  provides.

No client calls this artifact; other services do.
