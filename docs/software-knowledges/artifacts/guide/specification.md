# Guide specification

The behavior of the framework page. It holds no knowledge of any service or
flow.

## Model

The page is a few paragraphs of plain text, with one link for each part.

## Rules

| ID | Rule | Error |
| --- | --- | --- |
| GUIDE-1 | The page says, in short paragraphs, that the framework turns the governance of Artifact Driven into tools that developers and AI agents use. It lists the parts - governance, runbooks, scripts and the install script - with one sentence each and a short list of what is inside each, and says that each workspace gets from them its `CONTRIBUTING.md`, `AGENTS.md`, `CLAUDE.md`, agent definitions and skills, and shows the files of a workspace as a tree. It uses no promotional words. |
| GUIDE-2 | Each part on the page links the page of the rules it stands for, and the page states nothing those rules do not state. | — |
