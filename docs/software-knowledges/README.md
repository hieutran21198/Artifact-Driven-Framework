# Software knowledge

Established knowledge of the software, in four layers. System is shared:
every layer may cite it. Among goals, flows and artifacts, a layer cites only
the layers below it. The rules are in
[Artifact Driven](../governances/artifact-driven/knowledge.md).

In this framework the folder holds the reference pass: a small library lending
service, written from system down to client needs. A project replaces it with
its own knowledge and keeps the shape.

- [System](system/README.md): purpose, actors, services, clients, system-wide
  requirements and glossary.
- [Goals](goals/README.md): business outcomes and their success criteria.
- [Flows](flows/README.md): knowledge that crosses artifacts, the edges.
- [Artifacts](artifacts/README.md): one artifact per domain, each served by
  one service; the nodes.
