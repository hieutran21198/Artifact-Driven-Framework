For developers

Mention the rule in the test, so it can be counted.

// BK-3: only an available book can be lent.
func TestLendRefusesBookOnLoan(t *testing.T) {
	book := onLoanBook()
	err := book.Lend(member)
	assert.ErrorIs(t, err, ErrInvalidTransition)
}

Good to know

Tests

Tests are counted, not run. A rule with a test is not proof that it works.

Changes

A change shows what it affects, not what it costs.

Plans

Plans and progress stay in your task tracker.
